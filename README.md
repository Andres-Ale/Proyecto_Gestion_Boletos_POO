#Sistema de Gestión de Venta de Boletos para Eventos

#Descripción
Desarrollo de clases e implementación de patrones de diseño para estructurar y gestionar el sistema de compra de boletos para eventos, promoviendo una arquitectura modular y robusta que mejora la organización del sistema, facilita su mantenimiento y optimiza la integración entre la lógica de negocio, la interfaz gráfica y la persistencia de datos

#Primer Entregable
Diagramas de clases e implementación en Java
